# 📚 TaskCampus - Sistema de Gestión de Tareas Académicas

## 📖 Descripción del Proyecto

TaskCampus es una aplicación web desarrollada para ayudar a estudiantes universitarios a organizar y gestionar sus tareas académicas de manera sencilla y eficiente.

El sistema permite registrar, visualizar, editar, eliminar y filtrar tareas académicas mediante una interfaz moderna y responsive. Además, ofrece un resumen estadístico para controlar el avance de las actividades pendientes y finalizadas.

El proyecto fue desarrollado aplicando la metodología **Spec Driven Development (SDD)** utilizando GitHub y Spec Kit para planificar y estructurar el desarrollo antes de implementar el código.

---

# 🎯 Objetivos del Sistema

- Registrar tareas académicas.
- Organizar actividades estudiantiles.
- Gestionar prioridades y estados.
- Visualizar tareas pendientes y finalizadas.
- Aplicar arquitectura basada en API REST.
- Utilizar persistencia local mediante archivos JSON.
